## 🚀 Panoramica

Questo repository contiene il codice sorgente del mio portfolio personale, attualmente ospitato su **GitHub Pages**. Non utilizza framework pesanti come React o Angular; è stato costruito da zero utilizzando **Vanilla HTML5, CSS3 e JS**, puntando alla massima velocità, pulizia del codice e un'esperienza utente (UX) memorabile.

## 🛠️ Tecnologie & Feature

- **Vanilla Stack:** HTML5 Semantico, CSS3 (Custom Variables) e JS Nativo.
- **Boot Sequence:** Animazione di avvio interattiva ispirata a un vero terminale Unix.
- **Scroll Animation:** Animazione fluida (60fps) a 514 frame sincronizzata con lo scorrimento della pagina.
- **Dark Theme Nativo:** Palette colori Cyberpunk/Emerald Green progettata per affaticare meno la vista.
- **Performance First:** Nessun builder, nessuna dipendenza Node.js, caricamento istantaneo.
- **SEO & Social Graph:** Meta tag completi per la condivisione sui social.
- **Custom 404:** Pagina d'errore a tema.

## 🌐 Deploy (GitHub Pages)

Il sito è pronto per essere eseguito ovunque senza configurazioni. Su GitHub, basta abilitare **GitHub Pages** puntando il branch main alla root / del repository.
